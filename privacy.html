Privacy Policy

YT Playlist Builder · last updated 28 September 2026

YT Playlist Builder is a personal program run by one person on their own computer. It has a single user, who is also its author. There is no server, no account system, and no other party involved.

What it accesses

With the owner's consent, the program uses the YouTube Data API to read and modify playlists in the owner's own YouTube account. Specifically it can create playlists, add videos to them, remove videos from them, and read back their contents. It requests the https://www.googleapis.com/auth/youtube.force-ssl scope, which is the narrowest scope YouTube offers that permits these writes.

What it stores

  • An OAuth token, kept in a file on the owner's own computer, readable only by the owner's account. It is never transmitted anywhere except to Google.
  • A list of which video IDs have already been seen, so the same upload is not added twice.
  • Video titles, descriptions and runtimes, used to write the summary email.

All of this lives on the owner's computer. None of it is uploaded, published, sold, or shared.

What is sent elsewhere

Two outside services are used, both at the owner's direction:

  • Anthropic's API receives the titles, descriptions and runtimes of newly added videos in order to write the summary. It does not receive the OAuth token or any account information.
  • An SMTP server (Gmail) delivers the summary email to the owner and one other named recipient.

What is not collected

The program collects no analytics, sets no cookies, has no telemetry, and contacts no service other than the ones named above. It does not access anyone else's Google account, and there is no mechanism by which it could.

Google user data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to operate the playlist features described on the home page. It is not used for advertising, not sold, and not transferred to anyone.

Revoking access

Access can be withdrawn at any time from Google Account permissions, which immediately stops the program from reaching the account. Deleting the token file on the computer has the same effect locally.
